# Inventário de Reutilização do Projeto

## 1. Objetivo

Este documento registra os componentes reutilizados no projeto individual
de Data Warehouse baseado no AdventureWorks.

O professor autorizou a reutilização do Data Warehouse e da ETL
desenvolvidos anteriormente, bem como dos materiais disponibilizados
durante a disciplina.

O objetivo é evitar reconstruções desnecessárias e concentrar o trabalho
individual na adaptação, integração, orquestração com Apache Airflow,
validação da ETL incremental, testes e documentação técnica.
